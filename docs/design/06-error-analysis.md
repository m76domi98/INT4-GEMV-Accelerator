# Stage 6: Error Analysis

**Status:** Not started · **Weeks:** 8 · **Depends on:** Stage 4 (results table); Stage 5 optional for the area side
**Exit criterion:** Plots and written breakdown complete, including at least one explained surprise.

## Goal

Explain where quantization error concentrates: by row, by magnitude, and by outlier channel. PRD G3, §10.

## Inputs

- Per-row error output from the Stage 1 golden model and Stage 4 runs
- Activation and weight statistics from the export script

## Design

- **Error by row:** max abs and RMSE per output row, for both variants. Plot as a sorted bar or a scatter against row norm.
- **Error by magnitude:** error vs. input activation magnitude and vs. weight magnitude.
- **Outlier channels:** identify input channels with large activation magnitude and check whether error clusters there.
- **Predictions:** compare with the Week 1 predicted results, and say which predictions were wrong and why.
- All plots generated by script into `results/`.

## Deliverables

- [ ] Error-by-row plot, both variants
- [ ] Error-by-magnitude plot
- [ ] Outlier-channel analysis
- [ ] Written breakdown, with predicted vs. measured comparison
- [ ] At least one explained surprise, logged in the decision log under type **surprise**

- Negative findings stay in. A variant that is worse is a result.
