# Stage 4: Variants Implemented and Measured

**Status:** Not started · **Weeks:** 5–6 · **Depends on:** Stage 3 (full layer bit-exact)
**Exit criterion:** Both variants selectable, run on the same testbench and data, with a results table.

## Goal

Implement the second variant of the chosen design decision and measure both on the same layer. PRD G2, FR7, FR9.

## Inputs

- Stage 3 full-layer design
- Stage 1 decision (recommended: per-channel vs. per-tensor requantization)

## Design

- **Selection:** a parameter (preferred) or a separate module behind the same interface. Pick one and keep it for both variants.
- **Variant A (baseline):** the design from Stage 3.
- **Variant B:** the other option of the chosen decision. Changes should stay inside the requantization path if the recommendation holds, so the comparison isolates one choice.
- **Measurement:** same testbench, same exported data, same seed. Results generated by script into `results/`.

### Week 6 gate

If Variant B is not finished by the end of Week 6, report Variant A fully and describe Variant B as planned work. Record the outcome in the decision log under type **gate**.

## Deliverables

- [ ] Variant selection mechanism
- [ ] Variant B passes the same bit-exact tests as Variant A (against its own golden model if the arithmetic changes)
- [ ] Results table: cycles, output error (max abs, RMSE) for both variants
- [ ] Week 6 gate outcome recorded

## Verification

- Both variants on the same test vectors. Differences must come from the variant, not the setup.
- If Variant B changes arithmetic, its golden model is a separate, dated entry in the spec. Do not edit Variant A's golden model to match.
